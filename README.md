  ## 制作テーマ１：福岡の観光名所

  ### 目的：福岡県の魅力や観光地の良さを多くの人に知ってもらうため。福岡県には歴史的な建造物や自然豊かな景観、グルメスポットなど様々な魅力があるが、県外の人には十分に知られていない場所も多い。本制作を通して福岡県の観光資源を紹介し、観光への興味を持ってもらうこと

  ### ページ構成

  #### ページ1　「全体の概要」

　　　-　全体の概要を説明する
　　　-　このWEBページで紹介するスポットの一覧を説明する
　　　　　　　　-　一覧のリストを入れる


  #### ページ２　「太宰府天満宮」

　　-　学問・文化芸術の神様として知られる菅原道真公を祀る神社で、全国約1万2千社ある天満宮の総本宮です。受験シーズンには多くの参拝者が訪れ、境内には歴史ある建物や美しい庭園が広がっています。四季折々の自然も楽しめる、福岡県を代表する観光名所です。

  #### ページ３　「福岡タワー」

　　-　全長234メートルを誇る、日本一高い海浜タワーです。展望室からは福岡市街や博多湾を360度見渡すことができ、昼と夜で異なる景色を楽しめます。ガラス張りの外観が特徴で、福岡のシンボルとして多くの観光客に親しまれています。

  #### ページ４　「櫛田神社」

  　-　博多の総鎮守として古くから地域の人々に親しまれている神社です。毎年7月に開催される博多祇園山笠の中心となる神社として有名で、境内には一年中飾られている飾り山笠も見ることができます。博多の歴史や文化を感じられる人気の観光スポットです。

  #### ページ５　「門司港レトロ」

    - 明治から大正時代にかけて国際貿易港として栄えた門司港周辺を再整備した観光エリアです。歴史的な洋風建築が数多く残され、レトロな街並みを散策できます。港の景色と歴史ある建物が調和し、写真撮影にも人気のスポットとなっています。

  #### ページ６　「桜井二見ヶ浦」

    - 糸島市にある美しい海岸で、海上に浮かぶ夫婦岩と白い大鳥居が有名な景勝地です。夕日の名所としても知られ、夏至の頃には夫婦岩の間に夕日が沈む幻想的な景色を見ることができます。福岡を代表する絶景スポットの一つです。

  #### ページ７　「海の中道海浜公園」

    - 博多湾と玄界灘に囲まれた広大な国営公園です。季節ごとに咲く花々や広い芝生、サイクリングコースなどが整備されており、自然を満喫できます。また、小動物とふれあえる施設もあり、子どもから大人まで楽しめる人気の観光スポットです。

  #### ページ８　「秋月城跡」

    - 朝倉市にある秋月藩の城跡で、「筑前の小京都」と呼ばれる歴史ある町並みが残っています。現在は石垣や黒門などが残され、春は桜、秋は紅葉の名所としても有名です。自然と歴史が調和した落ち着いた雰囲気を楽しめます。


  #### ページ９　「柳川川下り」
  
    - 柳川市を巡る掘割をどんこ舟でゆったりと進む観光です。船頭による案内や地域の歴史を聞きながら、水辺の風景や四季折々の自然を楽しめます。約400年前から続く水路を活用した柳川ならではの観光で、多くの観光客に親しまれています。

  


  制作テーマ２：ヨーロッパの名所紹介
　  概要：

　目的：近年、海外旅行の情報収集はインターネットを利用することが一般的となっていが、多くの観光サイトは情報量が多く、初めて海外旅行を計画する人にとっては必要な情報を見つけにくい場合があ　る。そこで、世界各国の名所について、歴史や見どころ、アクセス方法などを分かりやすくまとめたWebサイトを制作し、利用者が旅行先を比較・検討しやすいサイトを目指す。
